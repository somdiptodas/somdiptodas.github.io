Privacy policy: Simply AI uploader

Last updated: October 8, 2026.

Simply AI uploader is a private tool used only by its owner, Somdipto Das, on YouTube channels he owns.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails, captions and playlists, and post or pin comments on the owner's channels. It may read YouTube Analytics reports for those channels.

What it stores

Its access token is stored only on the owner's own computer. Channel data it reads stays on that computer.

Sharing

It does not sell, share or transfer any Google user data to anyone, and it does not use that data for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
